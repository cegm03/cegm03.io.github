# CLIMAGUAY ❄️

Sitio web estático moderno para una empresa de venta e instalación de aires acondicionados en Guayaquil, Ecuador.

## 📌 Descripción

CLIMAGUAY es una landing page diseñada para promocionar servicios de climatización, venta e instalación de aires acondicionados.
El proyecto fue desarrollado como una página web estática con un diseño moderno, responsive y enfocado en brindar una experiencia visual profesional y atractiva.

La página transmite frescura, tecnología y confianza mediante una interfaz limpia inspirada en sitios modernos de tecnología y climatización.

---

## 🎯 Objetivo del Proyecto

Desarrollar una página web estática que permita:

* Promocionar servicios de climatización
* Mostrar productos de aire acondicionado
* Presentar beneficios y testimonios
* Facilitar el contacto con clientes potenciales
* Aplicar buenas prácticas de diseño web y estructura semántica HTML

---

## 🛠️ Tecnologías Utilizadas

* HTML5
* Tailwind CSS
* CSS3
* JavaScript (mínimo para interacciones visuales)
* Google Fonts
* Material Symbols Icons

---

## 🎨 Características del Diseño

* Diseño moderno y responsive
* Landing page de una sola sección
* Paleta de colores azul marino, celeste y blanco
* Navegación suave entre secciones
* Tarjetas con efecto glassmorphism
* Sombras suaves y bordes redondeados
* Diseño optimizado para escritorio y dispositivos móviles
